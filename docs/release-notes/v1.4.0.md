## netlight v1.4.0

這個版本讓結論更誠實：說清楚這次實際確認了什麼，不把局部的問題說成整體，也指出連線卡在哪一個階段。不新增結論碼，也不新增任何網路連線。

### 下載
| 平台 | 建議下載（含中文使用說明 README.txt） | 只要執行檔（給 IT） |
|---|---|---|
| Windows（64 位元） | `netlight-windows-amd64.zip` | `netlight-windows-amd64.exe` |
| macOS（Apple 晶片） | `netlight-darwin-arm64.tar.gz` | `netlight-darwin-arm64` |
| macOS（Intel） | `netlight-darwin-amd64.tar.gz` | `netlight-darwin-amd64` |
| Ubuntu／Linux | `netlight-linux-amd64.tar.gz` | `netlight-linux-amd64` |

使用方式與先前版本相同，詳見 [README](https://github.com/RoccoLiang/netlight#怎麼執行)。

### 新功能
- **網站連線的分段計時**：同一次請求記錄查網址（DNS）、建立連線（TCP）、加密交握（TLS）與等待回應各花多久，不新增任何請求。連不上時指出停在哪一個階段，例如「停在：加密交握（TLS）」，比單純的「逾時」更容易判斷問題在哪裡。顯示在 `--detail`、網頁版技術細節與「複製回報給 IT」。經由代理時會註明 DNS 與 TCP 是連往代理伺服器。

### 判斷更準確
- **部分網址查不到**：只有部分網址查不到時，「網址查詢」顯示黃燈並列出查不到的主機（以前一律顯示正常）。網站因此連不上時，結論說明是「查不到網址」，不再說成網站本身異常。
- **只測自訂網站時**：結論說明「測試的網站都連得上，但這次沒有確認網際網路」，不再只說「網路正常」。
- **單位網路節點沒有回應、但可以上網時**：結論說明單位節點的狀況，並顯示單位的聯絡窗口；在單位外（例如在家）執行時，結論也會提醒這屬正常。結論碼仍為 `OK`、結束碼 0。

### 給腳本與 IT
- `--json` 的每個網站多一個 `phases` 物件：`dns_ms`、`connect_ms`、`tls_ms`、`wait_ms`（沒有觀察到的階段為 -1）、`reached`（最後完成的階段）、`stalled`（已開始但沒有完成的階段）。既有欄位不變。

### 驗證下載的檔案
- 校驗碼：`shasum -a 256 -c SHA256SUMS --ignore-missing`
- 建置來源證明：`gh attestation verify <檔案> --repo RoccoLiang/netlight`

### 已知限制
- Windows 的路由追蹤尚未在實體電腦上驗證。
- 經由 HTTP 代理時，代理本身拒絕連線（CONNECT 失敗）不會被標成獨立的階段。
- 執行檔沒有數位簽章，Windows 與 macOS 第一次執行會跳出安全提示。
