## netlight v1.3.0

這個版本讓 netlight 看得更遠：可以檢查單位內部的網路節點，在終端機畫出網路經過的路線，並追蹤往網際網路的逐站路徑。

### 下載
| 平台 | 建議下載（含中文使用說明 README.txt） | 只要執行檔（給 IT） |
|---|---|---|
| Windows（64 位元） | `netlight-windows-amd64.zip` | `netlight-windows-amd64.exe` |
| macOS（Apple 晶片） | `netlight-darwin-arm64.tar.gz` | `netlight-darwin-arm64` |
| macOS（Intel） | `netlight-darwin-amd64.tar.gz` | `netlight-darwin-amd64` |
| Ubuntu／Linux | `netlight-linux-amd64.tar.gz` | `netlight-linux-amd64` |

使用方式與 v1.2.0 相同，詳見 [README](https://github.com/RoccoLiang/netlight#怎麼執行)。

### 新功能
- **單位網路檢查點**：設定檔新增 `checkpoints`，可列出單位防火牆、內部 DNS、GSN DNS 等節點（最多 10 個，檢查方式為 `ping`、`dns` 或 `tcp:<埠>`）。有設定時多一盞「單位網路」燈，位於路由器與對外連線之間。README 附有政府機關（GSN）範例。
- **新結論 `ORG_NETWORK`**：單位設定的節點都沒有回應、而且連不出去時，判定問題可能在路由器、單位內部網路或出口設備，請你聯絡單位資訊人員（結束碼 1；設定檔的 `contact` 可用 `org_network`）。單位節點有回應但連不出去時，改為建議由資訊人員處理對外線路。
- **終端機路線圖**：在支援顏色與 emoji 的互動式終端機中，改以由上往下的路線圖呈現。檢查中各站逐一點亮，結束後標出第一個故障的站「◀ 斷在這裡」，之後改以虛線連接。
- **路由追蹤**：以一般權限追蹤往 1.1.1.1 的逐站路徑（最多 15 站、3 秒，與其他檢查同時進行，不延長檢查時間）。路線圖會在「對外連線」底下畫出經過的節點，標出路由器、單位網路檢查點與抵達點；連不出去時標出最後回應的節點。`--detail`、網頁版技術細節與「複製回報給 IT」也會附上路由。路由追蹤只是輔助資訊，不會改變判斷結果。
- **網頁版**：燈號依設定動態產生，設定檢查點時會顯示「單位網路」。

### 變更
- 輸出導向檔案或管線、`--plain`、`--json`、舊版 Windows 主控台，維持原本的列表輸出。
- 單位節點都沒有回應、但可以連到網際網路時（例如筆電不在單位網路內），「單位網路」顯示黃燈，其他檢查照常進行。

### 驗證下載的檔案
- 校驗碼：`shasum -a 256 -c SHA256SUMS --ignore-missing`
- 建置來源證明：`gh attestation verify <檔案> --repo RoccoLiang/netlight`

### 隱私
沒有遙測。新增的連線只有路由追蹤（送往 1.1.1.1 的 ICMP，TTL 1～15）與你在設定檔列出的單位網路檢查點。完整清單見 README 的「隱私與連線清單」。

### 已知限制
- Windows 的路由追蹤尚未在實體電腦上驗證。所在網路擋掉 ICMP 時（例如部分雲端環境），路由追蹤會沒有任何節點回應，但不影響其他判斷。
- 執行檔沒有數位簽章，Windows 與 macOS 第一次執行會跳出安全提示。
