## netlight v1.5.0

這個版本讓回報可以放心分享，並讓單位更精準地設定檢查點。不新增結論碼，也不新增任何網路連線。

### 下載
| 平台 | 建議下載（含中文使用說明 README.txt） | 只要執行檔（給 IT） |
|---|---|---|
| Windows（64 位元） | `netlight-windows-amd64.zip` | `netlight-windows-amd64.exe` |
| macOS（Apple 晶片） | `netlight-darwin-arm64.tar.gz` | `netlight-darwin-arm64` |
| macOS（Intel） | `netlight-darwin-amd64.tar.gz` | `netlight-darwin-amd64` |
| Ubuntu／Linux | `netlight-linux-amd64.tar.gz` | `netlight-linux-amd64` |

使用方式與先前版本相同，詳見 [README](https://github.com/RoccoLiang/netlight#怎麼執行)。

### 新功能
- **安全的回報摘要**：網頁版的「複製回報給 IT」改為複製摘要，只含結論碼、各燈狀態、結論、建議與聯絡窗口，不含這台電腦的 IP、網址與技術細節，可以放心貼到 LINE 群組。設定檔自訂的網站在摘要中寫成「設定檔第 N 個網站」（N 依設定檔 `targets` 的順序），不會帶出網站名稱或網址；單位名稱與聯絡資訊依設定顯示。新增「複製完整技術資料」按鈕，給協助你的資訊人員。
- **單位網路檢查點可標為參考**：設定檔的檢查點可加上 `"required": false`。可以上網時，參考節點沒有回應只在燈號註明「（參考）」，不影響結論、也不顯示單位聯絡窗口。沒有寫 `required` 時視為必要節點，已部署的設定檔行為不變。連不出去時，判斷單位網路本身是否中斷仍以全部節點為準。

### 設定檔範例
```json
"checkpoints": [
  { "name": "單位防火牆", "host": "10.1.0.1", "check": "tcp:443" },
  { "name": "內部入口網", "host": "10.1.0.20", "check": "tcp:443", "required": false }
]
```

### 驗證下載的檔案
- 校驗碼：`shasum -a 256 -c SHA256SUMS --ignore-missing`
- 建置來源證明：`gh attestation verify <檔案> --repo RoccoLiang/netlight`

### 已知限制
- 文字版與 `--json` 的輸出仍是完整內容；安全摘要只在網頁版提供。
- Windows 的路由追蹤尚未在實體電腦上驗證。
- 執行檔沒有數位簽章，Windows 與 macOS 第一次執行會跳出安全提示。
